# Как помочь проекту

Спасибо, что хочешь сделать Aura лучше! 💜

## Сообщить о баге или предложить идею

Открой [Issue](https://github.com/vtat318-sketch/aura-shell/issues/new/choose) и выбери шаблон. Для багов очень помогают:

- версия Aura или номер сборки из Actions;
- версия Windows;
- последние строки лога `%AppData%\Aura\aura.log` или файл `build-errors.txt`.

## Собрать проект

- Windows 10 или 11 x64.
- Проще всего — двойной клик по `build.bat`: он сам скачает .NET 8 SDK.
- Для разработки — Visual Studio 2022 с нагрузкой «Разработка классических приложений .NET» и `Aura.sln`.
- HTML-прототип: `python tools/build.py`, затем открой `prototype/index.html`.

## Правила кода

- C# с включёнными nullable-аннотациями, WPF без сторонних UI-библиотек.
- Никаких патчей Explorer и внедрения DLL — только стандартные API Windows.
- Всё, что меняет систему, должно сохранять прежнее значение и откатываться кнопкой «Вернуть всё как было».
- Тексты интерфейса — на русском, коротко и по делу.
- Новые темы кладутся в `themes/presets` и проверяются по `schema/theme.schema.json`.

## Pull request

1. Сделай ветку от `main`.
2. Проверь, что сборка в GitHub Actions зелёная.
3. Опиши в PR, что изменилось и как это проверить. Если менялся интерфейс — приложи скриншот.
4. Добавь строку в `CHANGELOG.md` в раздел следующей версии.
