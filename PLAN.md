# Aura Shell — план

## 1. Идея в одном предложении
Одно приложение, которое делает Windows 11 красивой целиком: панель задач, трей и часы, обои, анимации окон и проводник. Всё настраивается в одном хабе и ставится готовым пресетом в один клик, а сетапами можно делиться.

## 2. Чем отличаемся
- **Всё в одном.** Сейчас для такого сетапа нужно 4–6 программ (Windhawk + Lively/Wallpaper Engine + StartAllBack + Rainmeter + Nilesoft Shell…).
- **Один клик.** Пресет меняет сразу всё: цвета, панель, обои, анимации.
- **Хаб как Steam Workshop, но для всей системы.** Люди выкладывают свои конфиги, ставят лайки, устанавливают чужие.
- **Бюджет ресурсов — часть продукта.** Цифры в разделе 6, они проверяются на каждом релизе.

## 3. Что берём у других
Полная таблица — в `FEATURES.md`. Коротко:
- **Windhawk** (самые популярные моды): стилизация панели (~1,1 млн), центр уведомлений (~620 тыс.), анимация дока (~520 тыс.), проводник (~350 тыс.), анимации окон с «джинном» (~120 тыс.), часы (~122 тыс.).
- **Seelen UI**: док на любой стороне, режимы автоскрытия, обои на рабочий стол, тайлинг.
- **YASB**: группировка и превью окон, виджеты, мастер первой настройки.
- **Lively / Wallpaper Engine**: видео/веб/шейдерные обои, умная пауза, правила по приложениям («остановить и освободить память»), раскладки на несколько мониторов.
- **StartAllBack / Start11, Flow Launcher, Nilesoft Shell, Mica For Everyone** — Пуск, лаунчер, контекстное меню, стекло в окнах.

## 4. Обои и Wallpaper Engine
**Брать обои из мастерской Wallpaper Engine и раздавать их у нас нельзя.**
- Права на обои принадлежат их авторам. Даже сами разработчики WE для своего Android-приложения просили согласие авторов.
- Формат сцен (.pkg) закрытый.

**Что можно:**
- **«Импорт из Wallpaper Engine».** Если у человека куплен WE, Aura читает его папку в Steam и локально проигрывает видео- и веб-обои. Никаких загрузок в наш хаб и никакого распространения. Сцены — не поддерживаем.
- **Свои обои**: процедурные/шейдерные (лёгкие и красивые), заказ у художников, загрузки пользователей с галочкой «это моё / у меня есть права» + кнопка жалобы (DMCA).
- Стоки вроде Pexels/Unsplash не подходят: Pexels прямо запрещает перераспространение на платформах обоев и исключает такие приложения из API, Unsplash запрещает собирать похожий или конкурирующий сервис.

## 5. Архитектура
```
┌─────────────┐   named pipe   ┌─────────────────────────┐
│  Aura Hub   │ ◄────────────► │  Aura Shell (фон, ~0% ЦП) │
│ настройки │                │  панель · трей · часы  │
│ пресеты    │                │  флайауты · правила    │
│ сообщество│                └──────────┬──────────────┘
└──────┬──────┘                           │ запускает
       │ HTTPS              ┌──────────────┴───────────────┐
┌──────┴──────┐             │ Aura Wallpaper (отд. процесс) │
│ Hub backend │             │ libmpv / WebView2 / D3D11      │
│ (Supabase)  │             └──────────────────────────────┘
└─────────────┘             Aura Mods (C++ DLL, фаза 3) — анимации окон, проводник
```
- **Стек:** C# .NET 8 + WPF + **ManagedShell** (открытая библиотека из RetroBar/Cairo: список окон, трей, AppBar; лицензию проверить) + **WPF-UI** для Fluent-стиля. Хаб — на том же стеке.
- **Стекло (Acrylic/Mica)** — через DWM (DWMWA_SYSTEMBACKDROP_TYPE, скругления) или SetWindowCompositionAttribute, как в TranslucentTB. Нужен тест: сколько ЦП/FPS ест плавающая стеклянная панель.
- **Обои**: видео — libmpv (как в Lively) или Media Foundation, веб — WebView2, шейдеры — D3D11. Рисуем позади иконок через WorkerW/Progman (в 24H2 там изменения — Lively переписывал ядро).
- **Моды (фаза 3)**: C++ + MinHook, игры в исключениях. Альтернатива — генерировать конфиги для модов Windhawk (Taskbar Styler, Explorer Styler, Windows Animations).
- **Формат темы** `.aura` = zip с `theme.json` + картинки/видео. Только данные, проверка по схеме (`schema/theme.schema.json`), лимиты на типы и размер файлов.

## 6. Бюджет производительности
| Метрика | Цель |
|---|---|
| ЦП в простое | < 1% |
| ОЗУ панели (Shell) | < 80 МБ |
| Хаб закрыт | 0 МБ (отдельный процесс) |
| ГП на статичных обоях | 0% |

Как: события вместо опроса (WinEventHook), часы обновляются раз в минуту, композиция на ГП. Живые обои ставятся на паузу: полноэкранное окно/игра, батарея, обои перекрыты, правила по .exe («остановить и освободить память», как в WE). Режим «Эконом» выключает размытие и движение. Телеметрия — только по согласию.

## 7. Роадмап
- **Фаза 0 (сейчас):** дизайн, кликабельный прототип, формат темы v1, 6 пресетов, технические тесты (стекло + ManagedShell).
- **Фаза 1 — MVP (~6–8 недель):** панель с закреплёнными/запущенными приложениями, группировка, превью, перетаскивание, 3 раскладки, увеличение как в доке, несколько мониторов; трей + часы + флайаут; хаб с пресетами, настройками и импортом/экспортом; обои-картинки и видео с паузой; аварийное возвращение родной панели; автозапуск.
- **Фаза 2:** онлайн-хаб (аккаунты, публикация, лайки, модерация), импорт из WE, веб/шейдерные обои, Пуск + лаунчер, виджеты, наборы иконок.
- **Фаза 3:** стилизация проводника, анимации окон, Alt+Tab, контекстное меню, центр уведомлений.
- **Фаза 4:** тайлинг, темы по виртуальным рабочим столам, день/ночь по расписанию, облачная синхронизация, монетизация.

## 8. Риски
| Риск | Что делаем |
|---|---|
| Обновления Windows ломают патчи | Рисуем свою панель, а не патчим родную; моды проверяют версию системы |
| Античиты в играх | Никаких инъекций в игры, список исключений; в фазах 1–2 инъекций нет вообще |
| Антивирусы ругаются | Подпись кода, открытый код модов |
| Вредоносные темы в хабе | Только декларативные темы, проверка по схеме и лимиты |
| Права на обои | Раздел 4 |
| Слишком большой объём | Жёсткие границы MVP |

## Обновление: итоговый стек версии 0.1

- **WPF (.NET 8) + чистый Win32 через P/Invoke**, без NuGet-пакетов. WinUI 3 отложен: для панели-оверлея нужны прозрачные окна и полный контроль над стилями, а WPF даёт это без упаковки MSIX.
- Панель резервирует место через AppBar API (SHAppBarMessage), стандартная панель скрывается обратимо (автоскрытие + SW_HIDE, возврат при выходе и по `--restore`).
- Анимации сворачивания: снимок окна (PrintWindow) в прозрачном оверлее, системная анимация отключается только на время эффекта. DWM-миниатюры не рисуются на layered-окнах WPF.
- Видеообои: окно WPF с MediaElement, встроенное в WorkerW за иконками рабочего стола.
